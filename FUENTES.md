# ¿Qué Biblia se cita y qué fuentes no se usan?

## ¿Qué traducción bíblica se usa?

- **Traducción propia**, hecha para el libro.
- **El Nuevo Testamento de David Bentley Hart**, que el autor tiene entre sus fuentes.

Se decide en cada libro, y la decisión se registra en el repositorio de ese libro. Una vez elegida, las citas se respetan letra por letra en todo el libro.

## ¿Qué fuentes no se usan?

- **Elena G. White no se usa como fuente**, salvo que el autor lo pida en un lugar concreto.
- Ningún comentario, sistema teológico o autor reemplaza lo que muestran los cuatro Evangelios.
